# Python Function Practice

## About
This repository contains Python practice programs based on functions, loops, conditional statements, and basic problem-solving concepts. These programs are designed to improve Python programming skills and logical thinking.

## Topics Covered
- Functions in Python
- If-Else Statements
- For and While Loops
- Return Statements
- List Operations
- String Operations
- Random Number Generation
- Basic Problem Solving

## Programs Included
1. Even or Odd Function
2. Largest of Two Numbers
3. Print Numbers
4. Sum of Numbers
5. Multiplication Table
6. Count Even Numbers
7. Find Maximum in a List
8. FizzBuzz
9. Palindrome Checker
10. Count Vowels
11. Second Largest Number
12. Number Guessing Game
13. Grade Calculator

## Purpose
The purpose of this repository is to practice Python functions, understand programming logic, and build a strong foundation in Python.
